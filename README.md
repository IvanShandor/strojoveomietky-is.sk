# Ivan Shetelia – IS: машинні штукатурки

Односторінковий презентаційний сайт словацької будівельної компанії Ivan Shetelia – IS.
Сторінка презентує машинну та ручну штукатурку, шпаклювання, фарбування,
реконструкцію та контактні дані компанії, яка працює в Сеніці та її околицях.

Проєкт створений без framework-ів і без процесу збірки. Він використовує чисті
HTML, CSS і JavaScript, тому вихідні файли можна одразу відкривати та редагувати.

## Запуск

### Пряме відкриття

Найпростіший спосіб запуску — відкрити `index.html` у сучасному браузері.
Для локальних зображень цього зазвичай достатньо.

### Локальний сервер

Під час розробки зручніше використовувати простий локальний сервер, оскільки
він працює подібно до production-середовища та надійніше завантажує медіа.

```bash
python3 -m http.server 8000
```

Після цього відкрийте `http://localhost:8000`.

## Структура проєкту

```text
index.html       Головна HTML-сторінка та весь контент сайту
css/style.css    Змінні дизайну, розмітка, компоненти та адаптивність
js/script.js     Навігація, ефекти прокрутки, галерея, lightbox і форма
images/          Логотип, фотографії реалізацій і зображення сайту
README.md        Цей опис проєкту та інструкція з підтримки
```

## Структура сторінки

1. **Hero** — головне повідомлення, досвід, локація та контактні кнопки.

3. **Наші реалізації** — фотографії робіт у компактній галереї.
4. **Чому обрати нас** — короткі причини та основні переваги співпраці.
5. **Про нас** — опис компанії та підходу до роботи.
6. **Використовуємо якісні матеріали** — бренди матеріалів.
7. **Територія роботи** — міста, у яких компанія надає послуги.
8. **Контакти** — телефон, email і форма для потенційних клієнтів.

## Інтерактивність

### Навігація

- Шапка залишається у верхній частині екрана під час прокрутки.
- Після прокрутки її візуальний стан змінюється.
- Активний пункт навігації визначається за секцією у видимій області.
- На mobile меню відкривається кнопкою та оновлює атрибут `aria-expanded`.
- Посилання використовують плавну прокрутку з урахуванням фіксованої шапки.

### Анімації секцій

Елементи з класом `.reveal` відстежує `IntersectionObserver`. Коли вони
з'являються у видимій області, отримують клас `.visible` і показуються через CSS-анімацію.

### Галерея фотографій

- `images/Ukážky2.jpg` — велика головна фотографія галереї.
- `images/Ukážky3.jpg`, `images/Ukážky4.jpg` і `images/Ukážky5.jpg` — додаткові фотографії.
- Кожен елемент має `data-src`, який визначає джерело для lightbox.
- Lightbox показує вибрану фотографію у збільшеному вигляді.
- Галереєю можна керувати кліком, Enter/Space, стрілками та Escape.

### Контактна форма

Форма перевіряє, чи заповнені ім'я, телефон і повідомлення. Повідомлення про
помилки показуються під час введення та після надсилання. Оскільки це статичний
frontend без backend, надсилання є лише візуальною симуляцією успішної дії.

## Медіа

Локальні файли у папці `images/` мають назви з діакритичними символами, тому
під час переміщення або перейменування потрібно оновити посилання в `index.html`.
Під час заміни фотографій оновіть відповідні значення `src` і `data-src` в
`index.html`, щоб звичайний перегляд і lightbox використовували один файл.

Деякі ілюстративні фотографії в секції послуг завантажуються з Unsplash.
Перед розгортанням на production-сервері варто перевірити доступність зовнішніх
URL або замінити їх локальними оптимізованими зображеннями.

## Налаштування дизайну

Найчастіше глобальні налаштування розташовані в блоці `:root` файлу `css/style.css`:

- `--color-*` змінюють колірну палітру;
- `--container` визначає максимальну ширину контенту;
- `--shadow` налаштовує тіні;
- `--radius` визначає стандартне заокруглення.

Адаптивні правила розділені на breakpoint-и `1100px`, `820px` і `520px`.
Після зміни розмірів галереї перевірте desktop і телефон, оскільки фотографії
використовують різну сітку на різних ширинах екрана.

## Технічні примітки

- Проєкт не використовує npm, bundler або frontend-framework.
- JavaScript запускається після події `DOMContentLoaded`.
- CSS використовує зовнішню родину шрифтів Inter і локальні правила компонентів.
- SVG-іконки та карта вбудовані безпосередньо в HTML і не потребують окремих запитів.
- Перед передачею змін JavaScript можна перевірити командою:

```bash
node --check js/script.js
```
