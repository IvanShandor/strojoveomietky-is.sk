# Ivan Shetelia – IS Stroje omietky

Jednostránkový web pre slovenskú stavebnú spoločnosť vytvorený v čistom HTML, CSS a JavaScript.

## Spustenie

Stačí otvoriť súbor `index.html` v prehliadači.

## Štruktúra

- `index.html` – obsah stránky
- `css/style.css` – štýly
- `js/script.js` – interaktívne správanie
- `images/` – obrázky a logo

## Poznámka

Projekt nepoužíva frontendové frameworky ani build step.
